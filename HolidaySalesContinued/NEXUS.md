# Holiday Sales Continued

Shopkeepers don't close for festivals that aren't on their map anymore. A continuation of atravita's [Holiday Sales](https://www.nexusmods.com/stardewvalley/mods/13050), updated for Stardew Valley 1.6.15 and no longer requiring AtraCore.

## Features
- Stores, locked doors and phone calls to shops stay open when the festival is somewhere else.
- The Help Wanted board keeps its daily quest when the festival isn't in town.
- The trash bear, Ginger Island visits, gifting and tool pickup messages follow the same rule.

## Configuration
Edit `config.json` or use Generic Mod Config Menu.
- **Closed**: vanilla. Stores close on festival days.
- **Map Dependent** (default): every vanilla festival counts as a Pelican Town festival, so vanilla shops close for it like in vanilla. Festivals from mods with their own region (Ridgeside Village, East Scarp, ...) leave Pelican Town shops open, and vice versa.
- **Open**: stores never close for festivals. Shops on a festival's map (Pierre's during the Egg Festival) are still unreachable, since you can't enter that map before the festival.

## Requirements
- Stardew Valley 1.6.15, SMAPI 4.0+.
- Optional: Generic Mod Config Menu.
- Works in single player, multiplayer and split-screen.

## Install
Unzip into `Stardew Valley/Mods` and run the game through SMAPI. Remove the original Holiday Sales if you have it.
