# Giant Crop Fertilizer Continued

Continuation of [atravita's Giant Crop Fertilizer](https://www.nexusmods.com/stardewvalley/mods/11620) for Stardew Valley 1.6, without AtraCore or Json Assets.

Apply the fertilizer anywhere in a 3×3 of a giant-crop-capable crop; when the crop is fully grown, a giant crop forms (chance configurable, guaranteed by default) and the fertilizer is used up. Sold in Mr. Qi's gem shop for 5 Qi gems; Big Slimes on Skull Cavern floor 120+ with dangerous mines active can drop it.

Config (GMCM supported): `GiantCropChance` (0–1.1, above 1 = always), `AllowGiantCropsOffFarm`.
